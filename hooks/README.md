# hooks/

`backup.sh` 在停某个项目的容器**之前**，会查找 `hooks/<项目名>.pre-stop`；存在且可执行就运行：

```
hooks/<项目名>.pre-stop <项目名> <项目目录> <compose 组数> <裸容器数>
```

- 退出 0：继续（stdout 会记入日志）
- 退出非 0：**跳过该项目**（不停机、不备份），发告警，整体结果标记失败

用途：某些项目停容器有前提条件（面板会级联停托管实例、需要先触发应用内 flush 等），把断言写在这里，
而不是改 `backup.sh`。

`*.example` 是示例，启用时去掉后缀并 `chmod +x`。除示例外本目录内容不入 git。
